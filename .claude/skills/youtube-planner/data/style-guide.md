# 스타일 가이드 — 코너(korner) 채널

> 이 파일은 Style Analyzer가 자동으로 업데이트합니다.
> 수동 편집도 가능하지만, 에이전트가 덮어쓸 수 있으므로 피드백을 통한 업데이트를 권장합니다.

## 채널 기본 정보

- **채널명**: 코너 (korner)
- **구독자**: 129만
- **포맷**: 리얼리티 시트콤 브이로그
- **특징**: 스크립트 없음. 여러 명이 출연. 상황을 설계하고 자연스러운 리액션을 촬영.

## 상태: 세부 분석 필요

채널 기본 정보는 입력되었으나, 기존 콘텐츠 샘플이 아직 분석되지 않았습니다.

### 시작하려면:
1. `data/samples/`에 기존 영상 정보를 넣어주세요.
   - 영상 제목 + 조회수 리스트
   - 과거 기획 메모
   - 잘된 영상 / 안 된 영상 정보
2. "스타일 분석해줘"라고 말하면 Style Analyzer가 분석을 시작합니다.

### 또는 직접 알려주세요:
- 고정 출연진이 누구인지, 각자 캐릭터가 어떤지
- 어떤 유형의 영상이 조회수가 잘 나오는지
- 절대 하지 않는 유형의 콘텐츠
- 편집 스타일 (자막 톤, 브금, 편집 속도 등)

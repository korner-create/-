# 스타일 가이드

> 이 파일은 Style Analyzer가 자동으로 업데이트합니다.
> 수동 편집도 가능하지만, 에이전트가 덮어쓸 수 있으므로 피드백을 통한 업데이트를 권장합니다.

## 상태: 초기화 필요

아직 샘플 콘텐츠가 분석되지 않았습니다.

### 시작하려면:
1. `data/samples/` 디렉토리에 기존 유튜브 기획안, 스크립트, 또는 영상 정보를 넣어주세요.
2. "스타일 분석해줘"라고 말하면 Style Analyzer가 분석을 시작합니다.

### 또는:
직접 스타일을 알려주셔도 됩니다. 예시:
- "나는 반말 톤이야"
- "제목은 질문형으로 쓰는 편이야"
- "영상 길이는 보통 10~15분이야"
- "테크 + 자기계발 주제를 다뤄"
